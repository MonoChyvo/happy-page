# Documentación del Proyecto

Esta carpeta contiene la documentación oficial del proyecto Modern App.

## Contenido

- [CHANGELOG.md](./CHANGELOG.md) - Registro de todos los cambios realizados en el proyecto
- [TODO.md](./TODO.md) - Lista de tareas pendientes y mejoras planificadas

## Propósito

El propósito de esta documentación es:

1. **Mantener un registro histórico** de los cambios realizados en el proyecto
2. **Planificar el desarrollo futuro** mediante la lista de tareas pendientes
3. **Facilitar la colaboración** entre miembros del equipo
4. **Proporcionar contexto** para nuevos desarrolladores que se unan al proyecto

## Convenciones

### Para el CHANGELOG

Seguimos el formato [Keep a Changelog](https://keepachangelog.com/es/1.0.0/), organizando los cambios en las siguientes categorías:

- **Añadido** - Para nuevas características
- **Cambiado** - Para cambios en funcionalidades existentes
- **Obsoleto** - Para características que serán eliminadas en versiones futuras
- **Eliminado** - Para características eliminadas en esta versión
- **Corregido** - Para correcciones de errores
- **Seguridad** - Para mejoras de seguridad

### Para el TODO

Las tareas se organizan por prioridad:

- **Prioridad Alta** - Tareas críticas que deben completarse lo antes posible
- **Prioridad Media** - Tareas importantes pero no urgentes
- **Prioridad Baja** - Mejoras deseables pero no esenciales
- **Ideas para Futuras Versiones** - Conceptos a considerar para versiones posteriores
- **Bugs Conocidos** - Problemas identificados que necesitan solución

## Actualización

Esta documentación debe actualizarse:

- Después de cada cambio significativo en el código
- Al completar tareas de la lista TODO
- Al identificar nuevos bugs o tareas pendientes
- Antes de cada release o despliegue importante
